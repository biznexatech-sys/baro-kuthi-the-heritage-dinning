Inline "read more" link — terracotta small caps with → and a copper underline that grows from the left on hover.

```jsx
<TextLink href="#story">Read the full story</TextLink>
<TextLink tone="dark" href="https://barokuthirajbari.com">Visit the Banquet House</TextLink>
```

- `tone="dark"` for terracotta / terracotta-deep bands. `arrow={false}` for tabs like "Skip".
